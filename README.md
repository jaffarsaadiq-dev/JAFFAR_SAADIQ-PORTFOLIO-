## 🌟 Overview

**Mohammed Jaffar Saadiq's** personal portfolio is a fully animated, dark-themed developer showcase built to leave a lasting impression. Every section is crafted with purpose — from the kinetic hero entrance to glassmorphic project cards and staggered scroll reveals.

> 💡 **Live Experience:** The site features 5 fully animated sections — **Hero, About, Toolkit, Selected Work, and Experience & Education** — each with micro-interactions and fluid transitions powered by Framer Motion.

This isn't just a portfolio. It's a **demonstration of engineering craft, design sensibility, and modern web development mastery.**

---

## 🚀 Key Features

| Feature | Details |
|:---|:---|
| ⚡ **Next.js 14 App Router** | Server-first architecture, optimized RSC + client hydration |
| 🎨 **Glassmorphism UI** | Backdrop blur, translucent borders, ambient gradient orbs |
| 🎬 **Scroll-Driven Animations** | Viewport-triggered Framer Motion entrances with stagger delays |
| ✨ **Micro-Interactions** | Hover-lift cards, interactive skill chips, fluid nav transitions |
| 📱 **Mobile-First Responsive** | Collapsible drawer nav, fluid grid layouts, touch-optimized |
| ♿ **Reduced Motion Support** | Gracefully disables animations via `prefers-reduced-motion` |
| 🔍 **SEO & OpenGraph Ready** | Meta tags, semantic HTML5, optimized web fonts |
| 🌑 **Dark Mode by Default** | Cyber-aesthetic dark palette with emerald/violet accent system |

## ⚡ Getting Started

### Prerequisites

```
✅ Node.js  v18.17+ (v20 LTS recommended)
✅ npm / yarn / pnpm
✅ Git
```

### Installation

**Step 1 — Clone the repository**
```bash
git clone https://github.com/jaffarsaadiq-dev/JAFFAR_SAADIQ-PORTFOLIO-.git
cd JAFFAR_SAADIQ-PORTFOLIO-
```

**Step 2 — Install dependencies**
```bash
npm install
```

**Step 3 — Start the development server**
```bash
npm run dev
```

**Step 4 — Open in browser**
```
http://localhost:3000
```

## 🌐 Deployment

### ▲ Deploy to Vercel _(Recommended)_

The easiest way to deploy is via [Vercel](https://vercel.com/):

1. Push your fork to GitHub
2. Log in to **Vercel** → **Add New Project**
3. Import `JAFFAR_SAADIQ-PORTFOLIO-`
4. Keep default settings (`npm run build`)
5. Click **Deploy** — live URL in under 60 seconds ⚡

### 🌍 Deploy to Netlify

1. Log in to [Netlify](https://www.netlify.com/) → **Add new site**
2. Connect your GitHub repository
3. **Build command:** `npm run build`
4. **Publish directory:** `.next`
5. Click **Deploy site**
