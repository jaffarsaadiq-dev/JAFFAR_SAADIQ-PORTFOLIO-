## 🌟 Overview

Welcome to my personal developer portfolio!

I'm **Mohammed Jaffar Saadiq**, an Artificial Intelligence and Data Science graduate interested in software development, data analytics, machine learning, and building intelligent applications.

This portfolio showcases my technical skills, development journey, academic projects, and practical experience through a modern, responsive, and interactive web experience.

## ⚡ Getting Started

Follow these steps to run the portfolio locally.

### Prerequisites

Make sure you have the following installed:

- Node.js 18.17 or later (Node.js 20 LTS recommended)
- npm, yarn, or pnpm
- Git

### Installation

**Step 1: Clone the repository**

```bash
git clone https://github.com/jaffarsaadiq-dev/JAFFAR_SAADIQ-PORTFOLIO-.git
```

**Step 2: Navigate to the project directory**

```bash
cd JAFFAR_SAADIQ-PORTFOLIO-
```

**Step 3: Install dependencies**

```bash
npm install
```

**Step 4: Start the development server**

```bash
npm run dev
```

**Step 5: Open the application**

Visit the following address in your browser:

```text
http://localhost:3000
```

The development server supports hot reloading, allowing you to see changes as you update the source code.

## 🌐 Deployment

The portfolio can be deployed using platforms that support Next.js applications.

### ▲ Deploy with Vercel (Recommended)

1. Push your project to GitHub.
2. Sign in to [Vercel](https://vercel.com/).
3. Select **Add New Project**.
4. Import your GitHub repository.
5. Configure the build settings.
6. Click **Deploy**.

Vercel automatically detects Next.js projects and configures the standard build process.

### 🌍 Deploy with Netlify

1. Sign in to [Netlify](https://www.netlify.com/).
2. Select **Add new site** and connect your GitHub repository.
3. Configure the build command as `npm run build`.
4. Use the Next.js runtime integration or Netlify's automatic Next.js framework configuration.
5. Deploy your application.
