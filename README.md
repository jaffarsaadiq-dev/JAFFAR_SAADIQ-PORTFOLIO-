## 🌟 Overview

This repository hosts the source code for **Mohammed Jaffar Saadiq's** personal portfolio website. Crafted with an eye for modern digital aesthetics, it features glassmorphism, dynamic ambient lighting glows, smooth entrance reveals, interactive hover-lift micro-interactions, and full accessibility accommodations.

Whether showcasing machine learning research, data analytics dashboards, or full-stack software development projects, this portfolio is designed to deliver a smooth and memorable user experience across all devices.

---

## 🚀 Key Features

- **⚡ Modern Next.js 14 App Router:** Server-first architecture with optimized client components for lightning-fast page loads.
- **🎨 Glassmorphism & Ambient Glow:** Dark-mode cyber-aesthetic with backdrop filters, translucent borders, and subtle floating gradient ambient orbs.
- **🎬 Scroll-Driven Animations:** Orchestrated entrances powered by **Framer Motion** with viewport tracking and staggered triggers.
- **✨ Micro-Interactions:** Hover-lift states on project cards, interactive skill chips, and fluid navigation transitions.
- **📱 Responsive & Mobile-First:** Clean responsive drawer navigation for handheld devices and expansive desktop layouts.
- **♿ Accessibility-First (Reduced Motion):** Respects OS-level `prefers-reduced-motion` settings to gracefully disable intense animations for sensitive users.
- **🔍 SEO & Metadata Ready:** Pre-configured OpenGraph tags, semantic HTML5 landmarks, and optimized fonts.

## ⚡ Getting Started

### Prerequisites

Ensure you have the following installed on your machine:
- **Node.js**: `v18.17+` (v20+ LTS recommended)
- **npm**, **yarn**, or **pnpm**
- **Git**

### Installation

1. **Clone the repository:**
   ```bash
   git clone https://github.com/jaffarsaadiq-dev/JAFFAR_SAADIQ-PORTFOLIO-.git
   cd JAFFAR_SAADIQ-PORTFOLIO-
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Start the local development server:**
   ```bash
   npm run dev
   ```

4. **View in your browser:**
   Open [http://localhost:3000](http://localhost:3000) in your web browser.

---

## 📦 Production Build

To create an optimized production build:

```bash
npm run build
npm run start
```

## 🌐 Deployment to Vercel

The fastest way to deploy this portfolio is using [Vercel](https://vercel.com/):

1. Push your repository to GitHub.
2. Sign in to **Vercel** and select **Add New Project**.
3. Import `JAFFAR_SAADIQ-PORTFOLIO-`.
4. Leave default build command (`npm run build`) and output directory.
5. Click **Deploy**.
